# Member Recall Skill (生产级交互式会员召回)

本 skill 引导运营团队完成一个严谨的、分阶段的生产级会员召回任务。

---

## 输入 (Input)

### 用户指令

| 类型 | 示例 | 说明 |
|------|------|------|
| **启动流程** | "启动生产级会员召回策略流程" | 开始完整的4步骤召回流程 |
| **单步指导** | "步骤1要做什么", "如何做动机洞察" | 获取特定步骤的执行指导 |
| **代码执行** | "运行召回脚本", "执行匹配策略" | 执行提供的Python代码 |
| **文件生成** | "生成人群包", "输出CSV" | 生成可导入营销平台的文件 |

### 必要输入

- **会员数据CSV文件**：包含完整字段的会员数据（如 `members_data_YYYYMM.csv`）
- **API Key**：用于调用 LLM 生成动机和文案

---

## 输出 (Output)

### 4步骤SOP流程

| 步骤 | 名称 | 输出 |
|------|------|------|
| **步骤1/4** | 动机洞察 | 用户确认的动机JSON（如 A/B/C/D 四类） |
| **步骤2/4** | 文案创生 | 用户审核确认的文案库（按动机分类） |
| **步骤3/4** | 策略匹配 | 启发式匹配策略确认，人群包生成 |
| **步骤4/4** | 产出交付 | `ai_group_YYYYMMDD.csv` 和 `control_group_YYYYMMDD.csv` |

### 交互要点

**步骤1：动机洞察**
> "【步骤1/4: 动机洞察】已对数据摘要分析，归纳出4种核心沉睡动机，请您审核、修改或确认。"

**步骤2：文案创生**
> "【步骤2/4: 文案创生】已为每个动机生成3版不同风格文案（A.尊享感, B.利益驱动, C.情感共鸣），请挑选最终使用的文案。"

**步骤3：策略匹配（冷启动）**
> "【步骤3/4: 策略匹配】采用基于专家规则的'智能启发式匹配'策略：
> - 高价值用户 (total_spend > 90分位) → 匹配'尊享感'文案
> - 价格敏感用户 (coupon_usage_rate > 75%) → 匹配'利益驱动'文案
> 是否批准执行？"

**步骤4：产出交付**
> "【步骤4/4: 产出交付】已按50/50比例生成A/B测试人群包。可直接导入营销平台执行。"

## 核心原则

### 生产级标准
- **无模拟**：每一步都基于真实数据和业务逻辑
- **无假设**：所有输出都可直接用于生产环境
- **可执行**：每个步骤都有明确的操作指令

### 交互式协作
1. **分步执行**：在标记为 `--- INTERACTION REQUIRED ---` 的地方暂停
2. **清晰汇报**：向用户展示AI生成的中间结果
3. **请求确认**：明确请求用户审核、修改、确认或批准
4. **忠实执行**：只有获得明确批准后才能继续下一步

---

## 启发式匹配策略（冷启动）

### 用户分层规则

| 用户类型 | 判定条件 | 匹配策略 |
|----------|----------|----------|
| **高价值用户** | total_spend > 90分位 | 优先匹配"尊享感"(StyleA)文案 |
| **价格敏感用户** | coupon_usage_rate > 75% | 优先匹配"利益驱动"(StyleB)文案 |
| **其他用户** | 其余情况 | 在对应动机文案中随机匹配 |

### 匹配逻辑

```python
# 伪代码逻辑
if segment == 'HighValue':
    匹配 StyleA (Premium/尊享感)
elif segment == 'PriceSensitive':
    匹配 StyleB (Benefit/利益驱动)
else:
    随机匹配该动机的任一文案
```

### 目的

此策略旨在：
- 最大化初次尝试的效果
- 为未来ML模型收集"特征-文案-效果"数据
