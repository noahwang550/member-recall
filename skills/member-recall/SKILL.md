# Member Recall Skill (会员召回方案)

本 skill 帮助您执行 AI 驱动的会员召回方案，包含完整的五阶段流程和 PPT 生成能力。

## 快速开始

### 生成演示文稿

运行以下命令生成完整的会员召回方案 PPT：

```bash
cd scripts && node create_ppt.js
```

这将生成 `AI会员召回方案.pptx` 文件，包含 11 页专业演示文稿。

## 五阶段召回流程概览

### 阶段一：地基与准备 (预计 1 周)

**核心目标**：统一思想，备好"粮草"

- 项目启动会：确定具体召回活动
- 定义"沉睡会员"：如 91-365 天未购买且历史消费 > 500 元
- 定义权益：已审批的优惠券（如 A-"满300减30券"）
- 定义指标：券核销率、人均GMV

**交付物**：
- 沉睡会员定义
- 活动权益池
- 核心指标定义

### 阶段二：LLM 深度画像归纳 (预计 1-2 周)

**核心价值**：利用 LLM 为每个沉睡会员打上"动机"标签

**四大流失原因归类**：

| 类型 | 描述 | 详情 |
|------|------|------|
| A | 价格敏感型流失 | 可能因为觉得贵或等待大促 |
| B | 产品厌倦型流失 | 对现有产品失去兴趣，可能等待新品 |
| C | 品牌关系淡漠型 | 忠诚度下降，可能只是忘了品牌 |
| D | 自然低频型用户 | 购买周期本身就很长，并非真正流失 |

**流程**：
1. 特征提取：拉取 RFM、购买周期、品类偏好等
2. 档案生成：自动生成结构化用户档案 Prompt
3. LLM 批量归因：调用 API 获取归因标签

**产出**：`user_id → motivation_label` 映射表

### 阶段三：LLM 批量创意生成与审核 (预计 1 周)

**沟通策略映射**：

| 动机类型 | 沟通策略 | 策略说明 |
|----------|----------|----------|
| A - 价格敏感 | 利益驱动 | 满减券、折扣、限时优惠 |
| B - 产品厌倦 | 新品/爆款引诱 | 新品上市、限量款、潮流趋势 |
| C - 品牌淡漠 | 情感关怀 | 品牌价值唤醒、会员权益回顾 |
| D - 自然低频 | 轻度触达 | 节日问候、温和提醒 |

**流程**：定义策略 → LLM 生成 → 人工审核 → 入库

**产出**：带 ID 的审核通过文案库（如 `NEW-01`, `PROFIT-01`）

### 阶段四：ML 模型匹配与 A/B 测试 (预计 1 周)

**两种匹配方式**：

**硬规则匹配（冷启动）**：
- 原因 A → 策略 A → 文案 A 组
- 同一策略下随机选择文案
- 适合：快速验证、零历史数据

**ML 模型匹配（进阶）**：
- 输入：用户特征 + 动机标签
- 输出：最优文案 ID
- 考虑因素：客单价、品类偏好、优惠券使用习惯、沟通风格偏好
- 适合：追求效果最大化

**A/B 测试设计**：
- 实验组 (AI组) - 50%：ML 模型匹配 + 个性化文案
- 对照组 (传统组) - 50%：统一文案 + 统一权益

### 阶段五：结果分析与复盘 (预计 2-3 周)

**分析维度**：
1. 核心指标对比：券核销率、人均GMV、活动ROI
2. 细分维度下探：各类文案效果对比、LLM归因准确性验证
3. 决策输出：效果提升验证、流程固化建议、扩展场景规划

**核心结论格式**：
> "本次MIP验证，'LLM洞察+内容+ML匹配'的新流程，相较传统方法：
> - 券核销率提升了 XX%
> - ROI提升了 YY%
> 下一步建议：将此流程固化，扩展到新客激活、复购提升等场景"

## 为什么选择 AI 召回方案？

| 维度 | 传统方式 | AI 方式 |
|------|----------|---------|
| 人群洞察 | RFM基础标签，无法洞察真实流失原因 | LLM深度分析，归因四大流失类型 |
| 内容生产 | 人工撰写，效率低、难规模化 | AI批量生成，多样化、可持续迭代 |
| 人-内容匹配 | 统一文案，"千人一面" | ML智能匹配，"千人千面" |
| 效果上限 | 核销率低，ROI提升困难 | 显著提升，可量化、可优化 |

**核心价值**：
- LLM归因 → 解决"说什么"（What）
- ML匹配 → 解决"怎么说"（How）
- 双引擎驱动，实现会员召回效果飞跃
